# Support

This repository is part of the FoggyKitchen training ecosystem.

The module is intended for educational and reusable infrastructure examples. It is not a managed service or production support contract.

For issues, open a GitHub issue with:

- OpenTofu or Terraform version
- AzureAD provider version
- Minimal configuration that reproduces the issue
- Sanitized error output

Do not include credentials, tokens, Terraform state, plan files, private keys, user passwords, or customer-sensitive identifiers in issues.
